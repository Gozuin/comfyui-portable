# Config Schema

## Local Profile

`config.local.json` is generated by `setup`. Main fields:

```json
{
  "schema_version": 1,
  "server": "http://127.0.0.1:8188",
  "timeout_seconds": 30,
  "poll_interval_seconds": 2,
  "max_wait_seconds": 900,
  "headers": {},
  "comfyui": {
    "root": "/path/to/ComfyUI",
    "python": "/path/to/python",
    "input_dir": "/path/to/ComfyUI/input",
    "output_dir": "/path/to/ComfyUI/output"
  },
  "workflows": {
    "txt2img": {
      "file": "workflows/txt2img.api.json",
      "bindings": {},
      "models": {},
      "defaults": {},
      "required_nodes": []
    }
  }
}
```

`comfyui.root`, `comfyui.python`, `input_dir`, and `output_dir` are diagnostic
and local-staging fields. The HTTP runner does not require them.

## Bindings

A binding points to one node input:

```json
{"node": "6", "input": "text"}
```

Role names recognized by the runner:

- `prompt`
- `negative`
- `seed`
- `steps`
- `cfg`
- `denoise`
- `sampler_name`
- `scheduler`
- `width`
- `height`
- `batch_size`
- `resolution`
- `reference` (object or list of objects)

## Model Bindings

```json
{
  "checkpoint": {
    "node": "4",
    "input": "ckpt_name",
    "value": "model-on-this-computer.safetensors"
  }
}
```

The descriptor supplies `node` and `input`. Setup supplies `value` from the
target computer.

## Defaults

Defaults are written back into the graph before each run:

```json
{
  "steps": 24,
  "cfg": 7.0,
  "width": 1024,
  "height": 1024
}
```

Command-line parameters override them.

## Required Nodes

`required_nodes` is the list of class types that must exist in `/object_info`.
Setup records this automatically and `doctor` validates it.
